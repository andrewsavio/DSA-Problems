# DSA Problems

Python solutions to data structures and algorithms problems, from easy to hard. Most files are named after their LeetCode problem number, for example `1.TwoSum.py`. Others are named by topic.

## Topics covered

- Arrays and two pointers: Two Sum, 3Sum, 4Sum, Container With Most Water, Rotate Array
- Sliding window: longest substring without repeating characters, minimum window substring
- Binary search: search in rotated array, Kth smallest in BST
- Linked lists: reverse, cycle detection, merge sorted lists
- Trees: binary tree construction, validate BST, lowest common ancestor
- Sorting and intervals: merge intervals, sort colours, next permutation
- Dynamic programming and subarrays: Kadane's algorithm, maximum product subarray, subarray sum equals K
- Strings: palindromes, anagrams, encode and decode strings

## Running a solution

Each file is a standalone solution that uses only the Python standard library, so there is nothing to install.

```bash
python 1.TwoSum.py
```

## Layout

```
<number>.<ProblemName>.py   # LeetCode-numbered solutions
<TopicName>.py              # topic-named solutions (e.g. KadanesAlgorithm.py)
```
